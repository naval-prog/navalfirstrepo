A chain is a linear workflow where steps run in a fixed sequence, such as prompt → model → parser. Each component passes its output to the next, making chains simple and suitable for straightforward tasks like summarization or basic RAG. A graph, such as in LangGraph, represents workflows as nodes and edges where execution can branch, loop, or follow different paths based on conditions or state. Graphs are designed for more complex, agentic systems involving decision-making and multiple tools.

A concrete example is an AI agent that decides whether to search the web, query a database, or ask the user for clarification, and can retry if the result is poor. A graph can support this conditional routing and looping, while a normal chain follows only one fixed path and cannot dynamically change its execution flow.
